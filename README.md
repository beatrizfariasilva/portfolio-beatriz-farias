## Como executar o projeto
1. Clone o repositório:
```bash
git clone https://github.com/beatrizfariasilva/portfolio-beatriz-farias.git
```

2. Instale as dependencias na sua máquina: 
```bash
npm install react-router-dom
```

3. Execute o projeto: 
```bash
npm start
```
